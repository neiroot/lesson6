# Калькулятор

Калькулятор в стиле iPhone с памятью, историей и AI-объяснением результата. HTML, CSS и JavaScript без сторонних библиотек; AI подключается через небольшую серверную функцию Vercel.

Опубликованное приложение: https://iphone-calculator-delta.vercel.app/

Репозиторий: https://github.com/neiroot/lesson6

## Локальный запуск

Нужен Node.js 18 или новее. Установка пакетов не требуется.

```sh
npm start
```

Откройте http://localhost:3000. Если порт занят, сервер выберет следующий свободный и напечатает адрес. `server.js` обслуживает локальную страницу и AI-маршрут; в Vercel вместо него автоматически запускается функция `api/explain.js`. Остановка — Ctrl+C.

## AI-объяснение результата

После вычисления и нажатия `=` кнопка «Объяснить результат» отправляет последнее выражение на сервер. OpenAI возвращает короткое объяснение на русском. AI не заменяет арифметическую логику калькулятора. Пока ответ загружается, повторный запрос заблокирован; новое вычисление отменяет показ устаревшего ответа.

Для локального запуска скопируйте `.env.example` в `.env.local` и задайте `OPENAI_API_KEY`. Файл `.env.local` исключён из Git; не вставляйте ключ в HTML, JavaScript браузера, README или коммиты. Перезапустите `npm start` после настройки.

В Vercel → Settings → Environment Variables добавьте `OPENAI_API_KEY` для Production и Preview. Также поддерживается сохранённая в этом проекте переменная `openaikey` для Production. Не используйте префиксы `VITE_`, `NEXT_PUBLIC_` и другие варианты публикации ключа в браузер. После настройки переменной нужен новый deploy. Модель по умолчанию — `gpt-6-luna`; её можно заменить через серверную переменную `OPENAI_MODEL`. OpenAI API требует доступную модель и средства на API-аккаунте.

Сервер принимает только арифметические выражения и проверяет результат, ограничивает размер запроса, время ответа и число выходных токенов. Передаётся только выбранное вычисление, без истории и памяти; Responses API вызывается с `store: false`. Ключ и внутренние ошибки провайдера не возвращаются посетителям. Тесты AI используют подменённый ответ провайдера и работают без ключа.

Демонстрационное ограничение — 5 запросов в минуту на IP и небольшой кэш на экземпляр функции. Это не глобальная защита расходов: для широкой публикации настройте лимиты бюджета OpenAI и правила Vercel Firewall. Перезапуск или масштабирование функции сбрасывает её локальные счётчики.

## Управление

Кнопки поддерживают мышь и касания. С клавиатуры: цифры, `+ - * /`, запятая или точка, Enter или `=` для результата, `%` для процентов, Backspace для удаления цифры, Escape для полного сброса. C очищает текущее число, AC — всё состояние.

Операции выполняются последовательно: `2 + 3 × 4 = 20`. Повторное `=` повторяет последнюю операцию. `200 + 10 % = 220`, `200 − 10 % = 180`, `200 × 10 % = 20`. Ввод ограничен 12 цифрами, результаты округляются до 12 значащих цифр для устранения типичных погрешностей дробей. Деление на ноль выводит «Ошибка»; начните ввод нового числа для продолжения.

## Память

Над основными кнопками находятся MS (сохранить текущее число), M+ (прибавить к памяти), M− (вычесть из памяти), MR (вызвать число) и MC (очистить память). Сохранённое значение показывается на экране рядом с индикатором M. MR можно использовать как число в текущей операции, например: `5 → MS → AC → 2 → + → MR → =` даёт `7`.

AC, Escape и ошибки вычислений не стирают память. Она хранится до нажатия MC или перезагрузки страницы; память вкладок независима. После MS, M+, M− или MR ввод цифр начинает новое число. Когда память пуста, MR и MC недоступны.

## История вычислений

Откройте «История вычислений» под клавиатурой: там отображаются 10 последних успешных операций после нажатия `=`, начиная с самой новой. Повторное `=` также добавляет запись; ошибки не сохраняются. Нажмите результат в истории, чтобы начать с ним новое вычисление, или «Очистить», чтобы удалить историю, сохранив экран и память.

AC и Escape не стирают историю. Она хранится только в текущей вкладке до перезагрузки страницы.

## Проверка

```sh
npm test
```

Тесты проверяют арифметику и память: сохранение, вызов в текущую операцию, M+/M−, очистку, сохранённый ноль и восстановление после ошибки.

## Сборка и GitHub Actions

```sh
npm run build
```

Сборка проверяет синтаксис JavaScript, наличие файлов приложения и ссылок на локальные ресурсы, затем создаёт `dist/` только с файлами фронтенда. Сторонние пакеты не нужны.

Workflow `.github/workflows/ci.yml` запускается при каждом `push` в любую ветку и при создании, обновлении или повторном открытии Pull Request. На Node.js 22 выполняются все тесты, включая функцию памяти, и сборка. Результаты доступны во вкладке [Actions](https://github.com/neiroot/lesson6/actions) и в разделе Checks соответствующего Pull Request. При ошибке тестов или сборки проверка становится красной. После слияния ветки workflow будет также находиться в `main`.

## Размещение в Vercel

1. Войдите в аккаунт Vercel.
2. Импортируйте репозиторий через Add New → Project. Выберите Framework Preset: Other, Build Command: `npm run build`, Output Directory: `dist`.
3. Нажмите Deploy. Настройки также сохранены в `vercel.json`.

Альтернатива без Git: из папки проекта выполните `npx vercel`, пройдите вход и настройку проекта; для публикации основной версии — `npx vercel --prod`. CLI при первом запуске загружается из npm. Для обычного калькулятора не нужна база данных. Для AI требуется серверная переменная `OPENAI_API_KEY`; использование OpenAI API оплачивается отдельно.
