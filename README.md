# Калькулятор

Классический калькулятор в стиле iPhone. Чистые HTML, CSS и JavaScript, без библиотек, сборки и серверной части приложения.

Опубликованное приложение: https://iphone-calculator-delta.vercel.app/

Репозиторий: https://github.com/neiroot/lesson6

## Локальный запуск

Нужен Node.js 18 или новее. Установка пакетов не требуется.

```sh
npm start
```

Откройте http://localhost:3000. Если порт занят, сервер выберет следующий свободный и напечатает адрес. `server.js` — только локальный сервер статических файлов; в Vercel он не запускается. Остановка — Ctrl+C.

## Управление

Кнопки поддерживают мышь и касания. С клавиатуры: цифры, `+ - * /`, запятая или точка, Enter или `=` для результата, `%` для процентов, Backspace для удаления цифры, Escape для полного сброса. C очищает текущее число, AC — всё состояние.

Операции выполняются последовательно: `2 + 3 × 4 = 20`. Повторное `=` повторяет последнюю операцию. `200 + 10 % = 220`, `200 − 10 % = 180`, `200 × 10 % = 20`. Ввод ограничен 12 цифрами, результаты округляются до 12 значащих цифр для устранения типичных погрешностей дробей. Деление на ноль выводит «Ошибка»; начните ввод нового числа для продолжения.

## Память

Над основными кнопками находятся MS (сохранить текущее число), M+ (прибавить к памяти), M− (вычесть из памяти), MR (вызвать число) и MC (очистить память). Сохранённое значение показывается на экране рядом с индикатором M. MR можно использовать как число в текущей операции, например: `5 → MS → AC → 2 → + → MR → =` даёт `7`.

AC, Escape и ошибки вычислений не стирают память. Она хранится до нажатия MC или перезагрузки страницы; память вкладок независима. После MS, M+, M− или MR ввод цифр начинает новое число. Когда память пуста, MR и MC недоступны.

## Размещение в Vercel

1. Войдите в аккаунт Vercel.
2. Импортируйте репозиторий через Add New → Project. Выберите Framework Preset: Other, без команды сборки, Output Directory: `.`.
3. Нажмите Deploy. Настройки также сохранены в `vercel.json`.

Альтернатива без Git: из папки проекта выполните `npx vercel`, пройдите вход и настройку проекта; для публикации основной версии — `npx vercel --prod`. CLI при первом запуске загружается из npm. Не нужны база данных, переменные окружения или платные услуги.
